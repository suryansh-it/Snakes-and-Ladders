# 🎲 Snakes and Ladders – Classic Board Game in Python

A classic **Snakes and Ladders** board game built with **Python** and **Pygame**, bringing nostalgic gameplay to your desktop! Designed to demonstrate **OOP concepts**, **matrix-based logic**, and Python's game development capabilities.

> 📌 *Ideal for beginners learning Pygame, object-oriented design, and grid-based game logic.*

---

## 🕹️ Features

- 🎮 Two-player turn-based gameplay
- 🐍 Snakes and 🔼 ladders placed randomly across the board
- 🎲 Dice rolling mechanics with animated turns
- 🧠 Matrix logic used for player movement and board layout
- 🏁 Win detection and replay option
- 💡 Simple, readable code with modular structure

---

## 🛠️ Tech Stack

- **Python**
- **Pygame** for game rendering and events
- **OOP (Object-Oriented Programming)** for clean game logic
- **VS Code** / Any Python IDE
